PATCH — Persistência obrigatória na transição Gate 2 -> Gate 3
--------------------------------------------------------------
Aprimoramento do protocolo unificado para exigir atualização explícita de metadata antes do início da revisão.

Resumo da release
-----------------
Esta release fortalece a consistência de estado no fluxo unificado ao tornar obrigatória a persistência de `gate: 3` e `status: review` antes da etapa de revisão.

Mudanças técnicas
-----------------
- A transição de Gate 2 para Gate 3 passou a exigir persistência explícita do metadata da story.
- Protocolo do implementador unificado reforçado para garantir handoff interno com estado consistente.
- Mensagem do comando `/batch --generate --unified` atualizada para refletir a regra de persistência obrigatória.
- Fluxo desacoplado de qualquer acionamento manual separado de revisor.

Documentação
------------
- README e orientações de batch unificado atualizados para explicitar a persistência de metadata antes da revisão.

Testes adicionados
------------------
- Testes de regressão para validar exigência de `gate: 3` e `status: review` no handoff interno.
- Cobertura de comando batch para confirmar instrução de transição obrigatória.

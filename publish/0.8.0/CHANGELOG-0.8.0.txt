SpecKit — Changelog 0.8.0
=========================
Data: 26/05/2026
Branch base: feat/speckit-high-value-gaps (merge para main)

MINOR — Impact Analysis, Retrospective, ADR Auto-Record & Pre-Gate Dry-Run
---------------------------------------------------------------------------
Esta release adiciona 5 features de alto valor focadas em qualidade de experiência
do desenvolvedor: análise de impacto via grafo, feedback loop de retrospectiva,
captura automática de decisões (ADR), dry-run de validators pré-gate e construção
automática (silenciosa) do grafo de dependências.

Resumo da release
-----------------
O plugin agora oferece comando `/impact` para visualizar blast radius antes de
qualquer alteração, `/retrospective` para identificar padrões recorrentes no
histórico de specs, ADR automático sem intervenção do usuário, e um hook
pré-gate que roda todos os validators em modo dry-run antes de avançar gates.

Mudanças técnicas
-----------------
- `package.json`: bump de versão para `0.8.0`, registro dos comandos `impact` e
  `retrospective` no chatParticipants.
- `src/participant/commands/impactCommand.ts` (novo): comando `/impact` com
  `GraphQuery.neighbors()` (2 hops, topN 15), `riskScore()` normalizado [0..100],
  tabela de nós afetados e sugestão de testes para risco ≥60.
- `src/participant/commands/retrospectiveCommand.ts` (novo): comando `/retrospective`
  que delega para `RetrospectiveAnalyzer` e emite relatório markdown com quick actions.
- `src/workflow/RetrospectiveAnalyzer.ts` (novo): motor de análise que lê audit log,
  trace, metrics e iteration counters. Computa avg iterations/gate, top findings
  recorrentes, gates com regressão e gera recomendações.
- `src/workflow/DecisionRecorder.ts` (novo): persiste ADR em `.speckit/decisions/`
  com numeração auto-incremental e slug kebab-case.
- `src/workflow/DecisionDetector.ts` (novo): detecta padrões de decisão (alternativa
  descartada, gate regression, mode switch, breaking change).
- `src/validator/auto/PreGateDryRunner.ts` (novo): orquestra validators sem
  side-effects, gera evidence em `.speckit/evidence/pre-gate-dry-run.md`.
- `src/graph/GraphAutoBuilder.ts` (novo): silent build de graph.json quando
  inexistente ou stale, com PerfBudget e degradação graciosa.
- `src/graph/GraphRuntime.ts`: expõe `ensureGraph()` público.
- `src/graph/GraphStore.ts`: aceita `IFileSystem` opcional.
- `src/participant/speckitParticipant.ts`: registra cases `impact` e `retrospective`.
- `src/participant/commands/reviewAutoCommand.ts`: integra hook `PreGateDryRunner`
  no início do fluxo, com opt-out `--skip-dry-run`.
- `src/participant/commands/agentCommand.ts`: hook fire-and-forget de decisão.
- `src/participant/commands/commitCommand.ts`: hook fire-and-forget de decisão.
- `src/participant/commands/validateCommand.ts`: hook fire-and-forget de decisão.

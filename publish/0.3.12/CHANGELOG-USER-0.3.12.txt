SpecKit — Novidades para usuários — 0.3.12
==========================================
Data: 01/05/2026

Resumo
------
Esta versão melhora bastante a consulta de histórico no chat do SpecKit. Agora você consegue navegar por sessões canônicas com mais clareza, filtrar por tipo de trilha e abrir rapidamente o detalhe de uma sessão específica para investigação.

O que mudou
-----------
- O comando `@speckit /history` continua exibindo a visão agregada de eventos.
- Novo comando `@speckit /history sessions` para mostrar um resumo das sessões canônicas com maior volume.
- Novo comando `@speckit /history session <termo>` para abrir o detalhe de uma sessão específica.
- O filtro por tipo continua disponível e pode ser combinado com os novos modos (`audit`, `trace`, `log`).
- Quando o termo informado em `session` corresponder a mais de uma sessão, o plugin passa a pedir refinamento de forma explícita.

Benefício prático
-----------------
- Menos tempo para localizar o contexto correto de uma execução.
- Investigação operacional mais rápida por sessão, sem precisar vasculhar tudo manualmente.
- Melhor leitura das trilhas quando há uso intensivo de /batch, /draft, /new e /fix.

Como usar
---------
1. Rode `@speckit /history` para visão geral dos eventos recentes.
2. Rode `@speckit /history sessions 8` para listar as principais sessões canônicas.
3. Rode `@speckit /history session implementador` para detalhar uma sessão por termo.
4. Se necessário, combine com tipo e limite, por exemplo: `@speckit /history session implementador trace 30`.

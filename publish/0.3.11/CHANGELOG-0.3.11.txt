SpecKit — Changelog 0.3.11
===========================
Data: 30/04/2026
Branch base: release/0.3.11

PATCH — Robustez operacional de desenvolvimento
-----------------------------------------------
Esta versão melhora a confiabilidade operacional do SpecKit em dois pontos comuns de execução local: commits em workspaces ainda sem repositório Git e testes de integração baseados em Testcontainers quando Docker não está disponível, mas Podman está instalado.

Resumo da release
-----------------
Release focada em robustez de execução para reduzir interrupções em sessões reais de desenvolvimento assistido. O plugin e os agentes passam a executar preflights explícitos para Git e runtime de containers antes de operações críticas.

Mudanças técnicas
-----------------
- O comando `/commit` passou a detectar workspace fora de repositório e executar `git init` automaticamente antes do commit.
- A abstração `GitOperations` passou a expor `isRepository` e `init` para inicialização controlada.
- Criado preflight Git compartilhado (`GitRepositoryPreflight`) para agentes implementadores.
- Agentes de Story e Fix passaram a aplicar recuperação controlada para erro `not a git repository` com retry único do mesmo commit.
- Criado preflight de containers (`ContainerRuntimePreflight`) com fallback Docker -> Podman.
- Fluxo de integração passou a considerar inicialização de `podman machine` antes de marcar teste como bloqueado.
- Mudança de comportamento intencionalmente restrita ao `/commit`; `/diff` não inicializa repositório.

Documentação
------------
- README atualizado para documentar que /commit inicializa Git automaticamente quando necessário.
- README atualizado para documentar o preflight Testcontainers com fallback para Podman.
